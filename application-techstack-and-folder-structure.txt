Interview Management Application - Tech Stack and Folder Structure

1. Application Overview
- Name: Interview Management Application
- Root package manager: npm
- Frontend: React (Create React App)
- Backend: Node.js + Express
- Database client: pg (PostgreSQL)
- Email: nodemailer
- HTTP client: axios
- Additional services: EmailJS browser SDK

2. Root-level Tech Stack
- Node.js/npm
- concurrently (devDependency)
- Root scripts:
  - start: runs backend and frontend concurrently
  - start:backend
  - start:frontend

3. Backend Tech Stack
- Node.js
- express
- cors
- dotenv
- pg
- nodemailer

4. Frontend Tech Stack
- react
- react-dom
- react-scripts
- axios
- @emailjs/browser
